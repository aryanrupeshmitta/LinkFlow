Section 2

Introduction & Problem Statement

Background & Challenges

Long URLs containing heavy query strings are visually unappealing, break in text sharing, and obscure marketing campaign performance. Existing public tools suffer from paywalls, lack password controls, impose strict rate limits, and crash without cloud database setups.

The LinkFlow Solution

A self-hostable, production-ready Full Stack platform combining dual-storage resilience, commercial security (passcode hashing & expiration controls), real-time Chart.js telemetry dashboards, and a complete v1 REST API.

Section 3

Objectives of the Case Study

1. REST Engine

Build Express.js REST API supporting single/bulk shortening, deletion, and redirection.

2. Dual Storage

Implement dual-engine storage abstraction (MongoDB + Local JSON) for zero-setup execution.

3. Security

Enforce passcode hashing, link expiration, max click limits, and rate limiting.

4. Telemetry

Develop dark glassmorphic UI with Chart.js analytics timelines and QR code previews.

Section 5

System Architecture & Dual Storage

  [ Client SPA Browser ]  <--->  [ Express Middleware & Router ]
           |                                  |
  (Chart.js / QR / UI)             [ Shortener Service Layer ]
                                              |
                                 [ Storage Abstraction Layer ]
                                      /               \
                      [ MongoDB Database ]   [ Local JSON Storage ]

Auto-detects MongoDB URI; falls back transparently to local file storage if database is offline.

Section 8

Results & Discussion

  • Redirection Latency: Sub-20ms HTTP redirection response time on local storage; sub-10ms on MongoDB.
  • Zero-Setup Guarantee: Anyone can clone and run immediately without database setup errors.
  • Commercial Viability: Complete feature parity with Bitly and TinyURL platforms including QR generation, UTM builders, and Chart.js dashboards.
  • Docker Deployment: Containerized with Dockerfile and docker-compose.yml for 1-command cloud launch.
